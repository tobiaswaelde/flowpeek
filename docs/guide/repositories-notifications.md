# Repositories and notifications

![Repositories](/screenshots/repositories.png)

Repository managers can inspect assigned repositories and their workflow history. System administrators can add a
repository only after validating its provider account; provider credentials remain encrypted on the server.

Notifications list repository-scoped channels, rules, and delivery history. Configure an Apprise URL only in ezRepo;
it is write-only and never returned to the browser after saving.
