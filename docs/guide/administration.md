# Administration and settings

![Provider accounts](/screenshots/provider-accounts.png)

System administrators manage provider accounts, repositories, users, and global retention settings. Every user can
change personal profile data, password, avatar, language, and appearance. MCP access tokens are shown once at creation;
store them in a secret manager and revoke them when no longer needed.

![Personal settings](/screenshots/settings.png)

For provider OAuth registration, manual webhooks, deployment, backup, and recovery, use the Operations and Providers
sections of this documentation.
